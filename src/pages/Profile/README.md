# Profile Page

## نظرة عامة
صفحة البروفايل تتيح للمستخدمين إدارة معلوماتهم الشخصية وتفضيلاتهم في التطبيق.

## الميزات الرئيسية

### 1. **الشريط الجانبي (Sidebar)**
- **معلومات المستخدم**: عرض اسم المستخدم والبريد الإلكتروني وتاريخ العضوية
- **الإحصائيات**: عدد عناصر المفضلة وعناصر السلة
- **قائمة التنقل**: روابط سريعة لأقسام مختلفة
- **زر تسجيل الخروج**: لتسجيل الخروج من الحساب

### 2. **المعلومات الشخصية**
- **تحرير المعلومات**: إمكانية تعديل البيانات الشخصية
- **الحقول المتاحة**:
  - الاسم الأول والأخير
  - البريد الإلكتروني
  - رقم الهاتف
  - العنوان الكامل (الشارع، المدينة، الولاية، الرمز البريدي، البلد)

### 3. **الطلبات**
- عرض تاريخ الطلبات السابقة
- حالة الطلبات
- تفاصيل الطلبات

### 4. **المفضلة**
- عرض المنتجات المضافة للمفضلة
- إمكانية إزالة المنتجات من المفضلة
- الانتقال السريع للمتجر

### 5. **الإعدادات**
- **الإشعارات**: إعدادات إشعارات البريد الإلكتروني وتحديثات الطلبات
- **الخصوصية**: إعدادات رؤية الملف الشخصي

## الملفات

### `Profile.jsx`
المكون الرئيسي لصفحة البروفايل يحتوي على:
- إدارة حالة التطبيق
- معالجة النماذج
- التنقل بين الأقسام
- التحقق من المصادقة

### `Profile.css`
أنماط CSS للصفحة تشمل:
- تصميم متجاوب
- دعم RTL للغة العربية
- أنماط للشريط الجانبي والمحتوى الرئيسي
- أنماط للنماذج والأزرار

## الاستخدام

### الوصول للصفحة
```javascript
// من خلال React Router
<Link to="/profile">الملف الشخصي</Link>

// أو من خلال التنقل البرمجي
navigate('/profile');
```

### التحقق من المصادقة
الصفحة تتحقق تلقائياً من وجود مستخدم مسجل دخول:
- إذا لم يكن هناك مستخدم، يتم التوجيه لصفحة تسجيل الدخول
- إذا كان هناك مستخدم، يتم عرض معلوماته

### تحرير المعلومات
```javascript
// تفعيل وضع التحرير
setIsEditing(true);

// حفظ التغييرات
handleSaveProfile();
```

## التصميم المتجاوب

الصفحة مصممة لتكون متجاوبة مع جميع أحجام الشاشات:

### الشاشات الكبيرة (>768px)
- عرض الشريط الجانبي والمحتوى الرئيسي جنباً إلى جنب
- عرض إحصائيات المستخدم في صفين

### الشاشات المتوسطة والصغيرة (≤768px)
- عرض الشريط الجانبي فوق المحتوى الرئيسي
- تكييف النماذج لعرض عمود واحد
- تحسين أحجام الخطوط والمسافات

### الشاشات الصغيرة جداً (≤480px)
- تبسيط تخطيط الأزرار والعناصر
- تحسين تجربة اللمس للأجهزة المحمولة

## دعم RTL

الصفحة تدعم الاتجاه من اليمين إلى اليسار للغة العربية:
- تخطيط العناصر يتكيف مع اتجاه النص
- الأيقونات والأزرار تتبع اتجاه اللغة
- النماذج والعناصر التفاعلية تدعم RTL
